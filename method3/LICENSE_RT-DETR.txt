PROJECT-SPECIFIC ADAPTATIONS
----------------------------

This project adapts the upstream implementation for one-class beach-bird
detection. The adaptations include:

  * configs/dataset/coco_detection.yml: one-class COCO dataset paths and bird
    category configuration;
  * configs/rtdetrv2/rtdetrv2_r50vd_m_7x_coco.yml: project training settings
    for the default three-level model;
  * configs/rtdetrv2/rtdetrv2_r50vd_m_7x_coco_stride4.yml: four-level feature
    pyramid using the backbone's stride-4 feature map;
  * tools/convert.py: project-created conversion from YOLO text labels to COCO
    JSON annotations;
  * references/deploy/rtdetrv2_torch.py: project inference and visualization
    entry point;
  * dataset paths, evaluation overrides, and documentation for this project.

The trained checkpoints and generated evaluation outputs are project artifacts
and are not part of the upstream RT-DETR distribution.
